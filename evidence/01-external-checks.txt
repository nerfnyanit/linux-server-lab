4. SSH は鍵認証以外を受け付けない / root ではログインできない
==================================================
PS> ssh -o PubkeyAuthentication=no -o PreferredAuthentications=password,keyboard-interactive <user>@54.92.104.136
<user>@54.92.104.136: Permission denied (publickey,gssapi-keyex,gssapi-with-mic).

PS> ssh root@54.92.104.136
root@54.92.104.136: Permission denied (publickey,gssapi-keyex,gssapi-with-mic).

判定:OK
- サーバーが提示する認証方式は publickey と gssapi のみ。password と keyboard-interactive は提示されない
- root は鍵を持っていても拒否される(PermitRootLogin no)
- gssapi は AlmaLinux の既定で有効。Kerberos は設定していないため使えないが、
  厳密には「publickey のみ」ではない(README「できなかったこと・未解決」に記載)
- ユーザー名は <user> に伏せている
